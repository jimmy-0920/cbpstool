# cbpstool

Clipboard Parent Sync Tool
\
\
Automate guardian (parent) group membership of any given Schoolbox group.\
Maintains accurate group membership and ensures only relevant users are enrolled in a series of user defined Schoolbox groups.
\
\
Review *cbpstconf.py* for automation settings and *cbpsthttp.py* for authentication settings (API Token) before running
\
\
Run with:
```
python cbpstool.py
```
